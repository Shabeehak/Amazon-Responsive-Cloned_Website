## Amazon Responsive Website Clone

A responsive clone of the Amazon homepage built using HTML, CSS, and JavaScript as part of my frontend development learning journey.
This project focuses on responsive layouts, UI behavior, and basic interactivity inspired by the Amazon website.

## Live Demo: https://shabeehak.github.io/Amazon-Responsive-Cloned_Website/

## Preview

A responsive Amazon-style interface featuring:

- Header with navigation & search bar
- Product sections and cards
- Responsive layout across devices
- Basic JavaScript-powered interactions

## Project Overview

This project was created to improve my responsive web design and JavaScript fundamentals by cloning a real-world e-commerce interface.
It is a frontend-only project intended for UI and interaction practice.

## Technologies Used

- HTML5 – Semantic structure
- CSS3 – Flexbox, Media Queries, Responsive Design
- JavaScript (Vanilla JS) – UI interactions
- GitHub Pages – Hosting

## Features

- Amazon-inspired UI design
- Fully responsive for mobile, tablet, and desktop
- Product layout sections
- JavaScript-based UI behavior
- Clean and maintainable code

## What I Learned

- Building responsive layouts using CSS
- Managing page structure with semantic HTML
- Adding basic interactivity with JavaScript
- Handling responsive navigation and layouts
- Deploying projects using GitHub Pages

## Learning Context

This project was developed as part of my frontend development learning journey to practice:

- Responsive web design
- UI cloning from real-world platforms
- JavaScript-driven frontend behavior
